# Dynamic Image Format Transformation

This example demonstrates how image transformation services like Cloudinary allow dynamic format changes via URL parameters (e.g., `f_webp`, `f_jpg`). It contrasts this with a static image URL where such parameters are typically ignored, illustrating the core concept of the accompanying blog post about Shopify's image handling limitations.

## Language

`html`

## How to Run

Save the code as `index.html`. Open `index.html` in your web browser.
